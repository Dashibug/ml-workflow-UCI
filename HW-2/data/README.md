# UCI Adult (Census Income) — паспорт датасета

**Источник:** UCI Machine Learning Repository, Adult dataset.  
**Оригинальные файлы:** `adult.data` (32 561 наблюдение) и `adult.test` (16 281 наблюдение).  
**Ссылка:** https://archive.ics.uci.edu/dataset/2/adult  
**Лицензия:** CC BY 4.0 (согласно UCI).

Цель — бинарная классификация: превышает ли годовой доход человека 50 000 USD.
В `data/processed/*.csv` цель хранится в колонке `income_gt_50k`:
0 — `<=50K`, 1 — `>50K`.

## Признаки

**Числовые (6):** `age`, `fnlwgt`, `education_num`, `capital_gain`, `capital_loss`, `hours_per_week`.

**Категориальные (8):** `workclass`, `education`, `marital_status`, `occupation`, `relationship`, `race`, `sex`, `native_country`.

Всего 14 исходных признаков + бинарная цель.
Символ `?` трактуется как пропуск. Метки тестового файла оканчиваются точкой, она удаляется при парсинге.

## Подготовка и версии

- `get_data`: загружает и проверяет SHA256 обоих исходных файлов, сохраняет их в `data/raw/`.
- `prepare_data`: делает стратифицированный split **только** официального train-файла с фиксированным `seed=42`.
- Официальный `adult.test` сохраняется без перемешивания и участия в подборе параметров.
- `data/processed/data_info.json` записывает размеры, доли положительного класса и SHA256 входных/выходных файлов.
